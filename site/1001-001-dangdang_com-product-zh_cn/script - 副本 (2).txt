//  ==========================
//   项目结构
//  ==========================

Project
    ├── CATE_LEVEL（分类层）
    │      └── UNIT_0 ~ UNIT_4
    ├── CL（分类列表）
    │      └── UNIT_0 ~ UNIT_4
    └── D（详情页）
           └── UNIT_0 ~ UNIT_4

//  ==========================
//   支持脚本常量（Script Constant），引用格式：@[脚本常量名]
//   只有=号前的脚本常量名，被“@[]”包住，才是可以被引用的脚本常量。
//   脚本常量的值必须是普通字符串，即：脚本常量不允许引用其它脚本常量。
//   支持先引用，再定义。因为脚本载入时，会先进行一遍脚本常量读取
//  ==========================

//  ==========================
//   配置文件解析说明
//  ==========================

// 本配置文件仅支持以下两种注释：

// 1. // 单行注释
//    - 仅在行首有效。
//    - 位于行中或行尾时，不视为注释。

// 2. /* */ 块注释
//    - 支持单行或多行。
//    - 可位于行首、行中或行尾。

//  ==========================
//  常量前缀说明
//  ==========================

//  命名规则：

//  1. 无 CATE_LEVEL_、CL_、D_、RAW_、ORIGIN_ 前缀
//     表示项目级配置。

//  2. CATE_LEVEL_
//     表示分类层级页面的信息，例如：
//     - 分类名称
//     - 分类链接
//     - 分类翻页

//  3. CL_ (Category List)
//     表示分类列表页可采集的字段。
//     其中：
//     CL_COMMON_   分类列表：共用字段
//     CL_PRODUCT_  分类列表：商品字段
//     CL_ARTICLE_  分类列表：文章字段

//  4. D_ (Detail)
//     表示详情页可采集的字段。
//     其中：
//     D_COMMON_    详情页：共用字段
//     D_PRODUCT_   详情页：商品字段
//     D_ARTICLE_   详情页：文章字段

//  5. CL_RAW_ (Category List RAW)
//     表示分类列表页采集到的原始数据。
//     其中：
//     CL_RAW_COMMON_   分类列表：原始共用字段
//     CL_RAW_PRODUCT_  分类列表：原始商品字段
//     CL_RAW_ARTICLE_  分类列表：原始文章字段

//  6. D_RAW_ (Detail RAW)
//     表示详情页采集到的原始数据。
//     其中：
//     D_RAW_COMMON_   详情页：原始共用字段
//     D_RAW_PRODUCT_  详情页：原始商品字段
//     D_RAW_ARTICLE_  详情页：原始文章字段

//  7. ORIGIN_（暂不使用）
//     表示来源网站、来源 URL 等信息。

// 说明：
// 同一数据字段同时存在 CL_ 与 D_ 前缀时，
// 表示该字段既可在分类页获取，也可在详情页获取，
// 只是提取规则不同。
