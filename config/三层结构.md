crawler 目录完整结构
一、三层结构概览

crawler/
├── CATE_LEVEL（分类层）
│   ├── cate_level_unit.py   → 单元过滤器配置
│   └── cate_level_item.py   → 分类层主配置
│
├── CL（分类列表层）
│   ├── cl_unit.py           → 单元过滤器配置
│   ├── cl_common.py         → 共用字段配置（商品、文章都有）
│   ├── cl_product_item.py   → 商品配置 = common + product + raw
│   └── cl_article_item.py   → 文章配置 = common + article + raw
│
└── D（详情页层）
│   ├── d_unit.py            → 单元过滤器配置
│   ├── d_common.py          → 共用字段配置（商品、文章都有）
│   ├── d_product_item.py    → 商品配置 = common + product + raw
│   └── d_article_item.py    → 文章配置 = common + article + raw

二、各层数据类详情
1. CATE_LEVEL 层
文件	数据类	职责
cate_level_unit.py	CateLevelUnitConfig	单个单元（css, xpath, child_filter）
CateLevelUnitItem	单元集合（unit0~unit4）
cate_level_item.py	CateLevel0Entry	0级入口（url, name）
CateLevelPageConfig	翻页配置
CateLevelConfig	单层分类规则（link_css, name_css等）
CateLevelItem	主配置（host_url + level0_list + level1~level4 + page）

# CateLevelItem 结构
CateLevelItem:
    host_url: str
    max_level: int
    page: CateLevelPageConfig        # 翻页
    level0_list: List[CateLevel0Entry]  # 入口列表
    level1: CateLevelConfig          # 1级规则
    level2: CateLevelConfig          # 2级规则
    level3: CateLevelConfig          # 3级规则
    level4: CateLevelConfig          # 4级规则（预留）
2. CL 层
文件	数据类	职责
cl_unit.py	ClUnitConfig	单个单元
ClUnitItem	单元集合（unit0~unit4）
cl_common.py	ClCommonConfig	共用字段（标题、图片、统计数据）
ClRawCommonConfig	辅助字段（标签、ID）
cl_product_item.py	ClProductConfig	商品专用（价格、销量、店铺）
ClProductItem	商品配置 = common + product + raw
cl_article_item.py	ClArticleConfig	文章专用（作者信息）
ClArticleItem	文章配置 = common + article + raw

# ClProductItem / ClArticleItem 结构
ClProductItem:
    common: ClCommonConfig      # 共用
    product: ClProductConfig    # 商品专用
    raw: ClRawCommonConfig      # 辅助

ClArticleItem:
    common: ClCommonConfig      # 共用
    article: ClArticleConfig    # 文章专用
    raw: ClRawCommonConfig      # 辅助
3. D 层
文件	数据类	职责
d_unit.py	DUnitConfig	单个单元
DUnitItem	单元集合（unit0~unit4）
d_common.py	DCommonConfig	共用字段（内容、时间）
DRawCommonConfig	辅助字段（标签、ID）
d_product_item.py	DProductConfig	商品专用（价格、销量、店铺、SKU）
DProductItem	商品配置 = common + product + raw
d_article_item.py	DArticleConfig	文章专用（作者、其他作者）
DArticleItem	文章配置 = common + article + raw
三、ScriptConfig 应如何引用
方案：直接使用 crawler 目录的数据类


# script_config.py 中的 ScriptConfig

from content_scraper.crawler.cate_level_item import CateLevelItem
from content_scraper.crawler.cate_level_unit import CateLevelUnitItem
from content_scraper.crawler.cl_unit import ClUnitItem
from content_scraper.crawler.cl_product_item import ClProductItem
from content_scraper.crawler.cl_article_item import ClArticleItem
from content_scraper.crawler.d_unit import DUnitItem
from content_scraper.crawler.d_product_item import DProductItem
from content_scraper.crawler.d_article_item import DArticleItem

@dataclass
class ScriptConfig:
    """采集脚本配置"""
    
    # ========== CATE_LEVEL 层 ==========
    cate_level: CateLevelItem = field(default_factory=CateLevelItem)
    cate_level_unit: CateLevelUnitItem = field(default_factory=CateLevelUnitItem)
    
    # ========== CL 层 ==========
    cl_unit: ClUnitItem = field(default_factory=ClUnitItem)
    cl_product: ClProductItem = field(default_factory=ClProductItem)  # 商品配置
    cl_article: ClArticleItem = field(default_factory=ClArticleItem)  # 文章配置
    
    # ========== D 层 ==========
    d_unit: DUnitItem = field(default_factory=DUnitItem)
    d_product: DProductItem = field(default_factory=DProductItem)     # 商品配置
    d_article: DArticleItem = field(default_factory=DArticleItem)     # 文章配置
    
    # ========== 其他配置 ==========
    scrapy_settings: Dict[str, Any] = field(default_factory=dict)
    show_windows: bool = True

五、需要讨论的问题
问题：CL/D 层的商品和文章配置如何选择？

当前 ScriptConfig 同时包含 cl_product 和 cl_article，但实际运行时：

电商站点只需 cl_product + d_product
内容站点只需 cl_article + d_article
两种方案：

方案	说明
A. 同时保留两者	ScriptConfig 同时包含 product 和 article，运行时根据站点类型选择使用哪个
B. 动态选择	添加 content_type 字段（product / article），解析时只填充对应配置
