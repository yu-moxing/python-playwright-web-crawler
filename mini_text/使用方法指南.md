# 如何在其他 Python 项目中使用 mini_text 工具库

---

## 方式 1：直接复制目录（最简单）✅

**步骤**：
```
您的其他项目/
├── mini_text/          ← 直接复制这个目录
│   ├── __init__.py
│   ├── file_utils.py
│   ├── string_utils.py
│   └── web_utils.py
├── your_main.py        ← 您的主程序
```

**使用方法**：
```python
# your_main.py
from mini_text import file_utils, string_utils, web_utils

# 直接使用
lines = file_utils.read_lines("data.txt")
if string_utils.has_chinese("测试"):
    print("包含中文")
```

---

## 方式 2：添加到 Python 路径（推荐）⭐

如果您不想每个项目都复制，可以：

### 方法 A：临时添加路径
```python
# your_main.py
import sys

sys.path.append("K:/scrapy_test/demo")

from mini_text import file_utils, string_utils, web_utils
```

### 方法 B：永久添加到环境变量
```python
# Windows PowerShell
$env:PYTHONPATH = "K:\scrapy_test\demo"

# 或在 Python 代码中
import sys
sys.path.insert(0, "K:/scrapy_test/demo")
```

---

## 方式 3：打包为标准库（最专业）🌟

将 `mini_text` 打包成可安装的包：

### 步骤 1：创建 `setup.py`
```python
# K:\scrapy_test\demo\setup.py
from setuptools import setup, find_packages

setup(
    name="mini_text",
    version="1.0.0",
    description="文本处理工具库",
    author="Your Name",
    packages=find_packages(),
    python_requires=">=3.6",
)
```

### 步骤 2：安装到系统
```bash
cd K:\scrapy_test\demo
pip install -e .  # 开发模式安装（可编辑）
```

### 步骤 3：在任何项目中使用
```python
# 任何 Python 项目都可以直接导入
from mini_text import file_utils, string_utils, web_utils

# 不需要复制文件，不需要添加路径
```

---

## 方式 4：发布到 PyPI（最通用）

如果想分享给其他人使用：

```bash
# 1. 注册 PyPI 账号
# 2. 打包
python setup.py sdist bdist_wheel

# 3. 上传
pip install twine
twine upload dist/*
```

然后任何人都可以：
```bash
pip install mini_text
```

---

## 🎯 推荐方案对比

| 方案 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| **直接复制** | 小型项目、临时使用 | 简单、无需配置 | 每个项目都要复制 |
| **添加路径** | 本地多项目共享 | 不重复复制 | 路径固定，不够灵活 |
| **pip install -e** | 开发调试阶段 | 可编辑、全局可用 | 需要配置 setup.py |
| **发布 PyPI** | 分享给他人 | 全局可用、版本管理 | 需要发布流程 |
